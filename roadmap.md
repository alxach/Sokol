# ROADMAP ПРОЕКТА «СОКОЛ»
> Система Отчетности, Контроля, Онлайн-логистики

---

## 1. Общая концепция

**СОКОЛ** — единая цифровая экосистема для:
- Спортивных школ
- Федераций
- Центров единоборств
- Тренеров
- Спортивных организаций

**Заменяет:**
- Excel-таблицы
- Ручную отчетность
- Разрозненные Telegram-чаты
- Бумажный документооборот
- Локальные базы данных

---

## 2. Главные цели проекта

| # | Цель | Описание |
|---|------|----------|
| 1 | **Централизация данных** | Все данные в одной системе |
| 2 | **Автоматизация отчетности** | Минимум ручного труда |
| 3 | **Аналитика** | Статистика в реальном времени |
| 4 | **Контроль филиалов** | Сравнение регионов и тренеров |
| 5 | **Масштабирование** | От клуба до федеральной федерации |

## 4. MVP версия

### Обязательно
- [x] Авторизация (Backend: JWT, регистрация, вход, refresh)
- [x] Спортсмены (Backend: CRUD API)
- [x] Тренеры (Backend: CRUD API)
- [x] Посещаемость (Backend: CRUD API)
- [x] Отчеты (Backend: CRUD API + шаблоны)
- [x] Группы и расписание (Backend: CRUD API, Frontend: ADR-013 + ADR-014 + создание/редактирование/состав + единая модалка)
- [x] Мероприятия и турниры (Backend: CRUD API)
- [x] Документооборот (Backend: CRUD API + согласование)
- [x] Аудит (Backend: логирование действий)
- [x] Excel export (Backend: openpyxl, Endpoint: `/api/v1/exports/excel/{type}`, Frontend: кнопка на страницах)
- [x] Excel import (Frontend: серверный парсинг через exceljs, модалка подтверждения)
- [x] Dashboard (Frontend: API-интеграция через TanStack Query, реальные данные с бекенда)
- [x] Login (Frontend: страница авторизации на TanStack Start)
- [x] Дизайн-система (Frontend: CSS-переменные, shadcn/ui, брендовые цвета)
- [x] Логотип (Frontend: SVG-логотип с соколом)

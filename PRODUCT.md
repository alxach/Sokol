# Product

## Register

product

## Users

**Тренеры** — заполняют отчёты, ведут посещаемость, управляют спортсменами и группами, планируют соревнования. Работают ежедневно, ценят скорость и надёжность.

**Руководители центров (admin)** — контролируют работу тренеров, утверждают отчёты, следят за KPI. Нужна прозрачность и сводная аналитика.

**Руководитель всех центров (director)** — видят всё по всем филиалам, сравнивают регионы, принимают управленческие решения.

## Product Purpose

СОКОЛ — единая цифровая экосистема для спортивных школ, федераций и центров единоборств. Заменяет Excel-таблицы, ручную отчётность, бумажный документооборот и разрозненные Telegram-чаты. Цель — убрать бюрократию из спорта, дать тренерам больше времени на тренировки, а руководителям — прозрачную статистику в реальном времени.

## Brand Personality

Надёжный, сильный, чёткий. Без лишнего пафоса — рабочий инструмент, которому доверяют. Как хороший спортивный зал: ничего лишнего, всё функционально, качественно и на своём месте.

## Anti-references

- **Старые гос. сайты** — серые, перегруженные таблицами, неудобные. СОКОЛ не должен выглядеть как бюрократическая система.
- Казённый тон, мелкий нечитаемый текст, бесконечные формы без подсказок.

## Design Principles

1. **Рабочий инструмент, не витрина.** Каждый пиксель должен помогать тренеру или руководителю сделать дело быстрее. Декоративные элементы — только если они не мешают функциональности.
2. **Ясность прежде всего.** Данные должны быть понятны с первого взгляда. Таблицы, статусы, KPI — без расшифровки.
3. **Предсказуемость.** Однотипные действия выглядят одинаково. Спортсмены, отчёты, расписание — единая логика интерфейса.
4. **Доступность с мобильных.** Тренеры работают в зале, с телефона. Интерфейс должен быть удобен на любом экране.
5. **Бренд через качество, не через украшательства.** Цвета и типографика задают тон, но не заменяют продуманный UX.

## Accessibility & Inclusion

- Базовый уровень — WCAG AA (контраст 4.5:1 для текста).
- Поддержка reduced-motion.
- Адаптивная вёрстка для работы с телефона и планшета.
- Тренировочные материалы доступны для людей с ограничениями зрения.

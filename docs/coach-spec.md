# Спецификация: Интерфейс тренера (coach)

> Версия 1.0 | Дата: 2026-06-01

---

## 1. Навигация (Sidebar)

Группа пунктов называется **«Моё»**.

| Раздел | Иконка | Роут |
|--------|--------|------|
| Дашборд | `LayoutDashboard` | `/` |
| Мои спортсмены | `Users` | `/athletes` |
| Мои группы | `Users` | `/groups` |
| Посещаемость | `ClipboardList` | `/attendance` |
| Соревнования | `Trophy` | `/competitions` |
| Отчёты | `FileText` | `/reports` |
| Профиль | `UserCog` | `/profile` |

**Чего НЕТ у тренера:** «Тренеры», «Документы», «Аналитика», «Настройки», «Управление».

---

## 2. Дашборд (`/`)

Блоки сверху вниз:

1. **KPI-карточки:** «Спортсменов: N», «Групп: N», «Сегодня: N занятия», «Посещаемость: N%»
2. **Статус отчёта:** жёлтый баннер, если есть черновик или просрочка
3. **Расписание на сегодня:** время → группа → кол-во спортсменов
4. **Последние действия:** активность своих спортсменов
5. **Ближайшие соревнования:** турниры, где участвуют его спортсмены

---

## 3. Мои спортсмены (`/athletes`)

Таблица с фильтром по `coach_id`:

- Колонки: ID, ФИО, дисциплина, разряд, возраст, статус, медали, рейтинг
- Поиск по имени, фильтры: дисциплина, статус
- **Действия:** создать, редактировать, архивировать (без удаления)
- Клик → карточка спортсмена (вкладки: информация, документы, достижения, посещаемость)

---

## 4. Мои группы (`/groups`) — *новый раздел*

- Список групп тренера: название, дисциплина, кол-во спортсменов, расписание
- Создать группу (название, дисциплина, описание)
- Редактировать (описание, расписание)
- Состав группы: добавить/удалить спортсмена
- Расписание группы: дни недели + время (CRUD)
- Удаление группы: ❌

---

## 5. Посещаемость (`/attendance`)

- Выбрать занятие из расписания → журнал
- Таблица со спортсменами группы и чекбоксами:
  - ☑ присутствует
  - ☐ отсутствует → причина (справка, неоправданное)
  - ☐ опоздание → минут
- [Сохранить]
- Авторасчёт % посещаемости группы

---

## 6. Соревнования (`/competitions`)

- Календарь/список турниров
- Для каждого: название, дата, город, участники от тренера
- Регистрация спортсмена на турнир (выбор из своих)
- Просмотр прошедших — результаты своих спортсменов

---

## 7. Отчёты (`/reports`) — *новый раздел*

Список с фильтрами по статусу:

| Статус | Цвет | Действия |
|--------|------|----------|
| Черновик (draft) | — | ✏️ редактировать, ➡️ отправить |
| Отправлен (submitted) | 🟡 | ожидание |
| Утверждён (approved) | 🟢 | просмотр |
| Отклонён (rejected) | 🔴 | просмотр + комментарий |

Создание:
- Выбор шаблона (недельный/месячный)
- Поля: кол-во спортсменов, проведено занятий, посещаемость (авто), травмы, работа с родителями, примечания
- [Сохранить черновик] / [Отправить на проверку]

---

## 8. Профиль (`/profile`)

- Фото (загрузка)
- ФИО (только просмотр)
- Телефон, специализация, биография
- Категории/разряды (просмотр)
- **Отпуск** (см. раздел 10)

---

## 10. Управление отпусками

### Где отображается
- **Профиль (`/profile`)** — просмотр и редактирование периодов отпуска текущего тренера
- **Карточка тренера** на странице `Тренеры` — просмотр при клике на строку

### Модель данных
Периоды отпуска хранятся как массив объектов `VacationPeriod`:
```
{ start: string (yyyy-MM-dd), end: string (yyyy-MM-dd) }[]
```

В БД — отдельная таблица `coach_vacations` (OneToMany к `coach`). На фронтенде — статические данные (`mock-data.ts`) с оверрайдами в `localStorage`.

### Как вычисляется статус
Функция `getCoachStatus(coach)`:
1. Проверяет `isOnVacation(coach.vacations)` — если сегодня попадает в любой период → `"Отпуск"`
2. Иначе возвращает `coach.status` (базовый: `"Активный"`, `"На больничном"`)

### Редактирование
- В режиме редактирования появляется кнопка «Добавить период»
- Дата выбирается через календарь (`DatePicker` из `Popover` + `Calendar`)
- Каждый период можно удалить (✕)
- После «Сохранить» данные пишутся в `localStorage` (временное решение до подключения API)
- Кнопка «Отменить» сбрасывает изменения к последнему сохранённому состоянию

### Ограничения
- Дата начала и конца обязательна для каждого периода
- Нельзя удалить все периоды через редактирование — пустой массив допустим (тренер без отпусков)
- API пока не подключён — данные синхронизируются только локально

## 11. Матрица отличий: Admin vs Coach

| Аспект | Admin | Coach |
|--------|-------|-------|
| Видит других тренеров | ✅ | ❌ |
| CRUD любых спортсменов | ✅ | ❌ (только своих) |
| CRUD любых групп | ✅ | ❌ (только свои) |
| Удаление спортсменов/групп | ✅ | ❌ |
| Утверждение отчётов | ✅ | ❌ |
| Аналитика по филиалу | ✅ | ❌ |
| Документооборот | ✅ | ❌ (только заявки) |
| Настройки / Управление | ✅ | ❌ |

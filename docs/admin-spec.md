# Спецификация: Интерфейс администратора центра (admin)

> Версия 1.0 | Дата: 2026-06-01

---

## 1. Навигация (Sidebar)

Группа пунктов называется **«Модули»**.

| Раздел | Иконка | Роут |
|--------|--------|------|
| Дашборд | `LayoutDashboard` | `/` |
| Спортсмены | `Users` | `/athletes` |
| Тренеры | `UserCog` | `/coaches` |
| Группы | `Users` (FolderTree) | `/groups` |
| Расписание | `Calendar` | `/schedule` |
| Посещаемость | `ClipboardList` | `/attendance` |
| Соревнования | `Trophy` | `/competitions` |
| Отчёты | `FileText` | `/reports` |
| Документы | `FileText` | `/documents` |

| Аналитика | `BarChart3` | `/analytics` |

**В подвал (footer)**: Пользователи, Центр, Аудит — отдельная группа **«Управление»**.

---

## 2. Дашборд (`/`)

Блоки сверху вниз:

1. **KPI-карточки:** «Спортсменов: N», «Тренеров: N», «Групп: N», «Посещаемость: N%», «Отчётов за неделю: N/M ⏳»
2. **График посещаемости:** по дням недели (bar chart)
3. **Топ проблемных групп:** 3 группы с низкой посещаемостью → [Детали]
4. **Сводка по отчётам:** сколько черновиков, отправлено, утверждено, отклонено
5. **Последние действия:** активность всех пользователей центра (аудит)

---

## 3. Спортсмены (`/athletes`)

Полный CRUD всех спортсменов центра:

- Таблица: ID, ФИО, дисциплина, разряд, возраст, город, тренер, статус, медали, рейтинг
- Поиск + фильтры: группа, тренер, статус, разряд
- **Создать** спортсмена (ФИО, дата рождения, спорт, тренер, группа)
- **Редактировать** карточку
- **Удалить** (permanent или archive)
- **Импорт** из Excel (массовая загрузка)
- **Экспорт** в Excel
- **Массовые операции:** смена тренера, группы, статуса
- Клик → карточка спортсмена:
  - Информация
  - Документы (медсправка, страховка, согласия)
  - Достижения (турниры, медали)
  - История разрядов
  - Посещаемость (график, статистика)
  - Перевод в другой центр

---

## 4. Тренеры (`/coaches`)

CRUD тренеров своего центра:

- Таблица: ФИО, дисциплины, групп, спортсменов, нагрузка, рейтинг, эффективность, статус
- **Создать** тренера (создаётся user + coach профиль)
- **Редактировать** профиль (ставка, специализация)
- **Уволить** (soft-delete)
- **Статистика** тренера: группы, спортсмены, посещаемость, отчёты

---

## 5. Группы (`/groups`)

CRUD всех групп центра:

- Таблица: название, дисциплина, тренер, кол-во спортсменов, макс. вместимость, расписание
- **Создать** группу
- **Редактировать**
- **Удалить**
- **Назначить тренера**
- Состав группы: добавить/удалить спортсмена
- **Передать** группу другому тренеру

---

## 6. Расписание (`/schedule`)

Полный CRUD расписания центра:

- Календарь (месяц/неделя/день)
- Фильтры: группа, тренер, день недели
- **Создать** занятие (группа, время, место, тренер)
- **Редактировать / удалить**

---

## 7. Посещаемость (`/attendance`)

Просмотр по всему центру:

- Сводка: средняя посещаемость по центру
- Таблица: группа → тренер → % посещаемости → динамика
- Heatmap по дням недели
- Детализация: клик на группу → журнал посещаемости
- **Не может отмечать** (только coach)

---

## 8. Соревнования / Мероприятия (`/competitions`, `/events`)

Полный CRUD:

- **Создать** соревнование / мероприятие
- **Редактировать, отменить**
- Календарь
- Просмотр заявок от тренеров
- Протоколы, результаты

---

## 9. Отчёты (`/reports`)

Просмотр всех отчётов центра + утверждение:

- Сводка: сколько сдано, утверждено, просрочено
- Список с фильтрами: статус, тренер, период
- **Статусы:** draft → submitted → approved / rejected
- **Действия:**
  - submitted → [Утвердить] / [Отклонить + комментарий]
  - После утверждения — отчёт lock
- Сравнение с прошлым периодом

---

## 10. Документы (`/documents`)

- Список документов центра
- Просмотр, согласование
- Статусы: draft → pending_approval → approved / rejected

---

## 11. Аналитика (`/analytics`)

- Посещаемость по группам (сравнение)
- Эффективность тренеров (KPI)
- Динамика спортсменов (прирост/убыль)
- Наполняемость групп

---

## 12. Управление (footer)

### Пользователи (`/users`)

CRUD учётных записей в своём центре:

- Список пользователей центра
- **Создать** учётку (email, пароль, ФИО)
- Назначить роль: `coach`, `methodist`, `viewer`
- Заблокировать / разблокировать
- **Не может** создавать `admin` или `superadmin`

### Центр (`/center`)

Редактирование своего центра:

- Название, адрес, телефон
- Регион

### Аудит (`/audit`)

Просмотр логов действий в центре:

- Кто, когда, что сделал
- Фильтры: пользователь, действие, дата

---

## 13. Профиль (`/profile`)

- Аватар
- ФИО, телефон, email
- Центр (просмотр)

---

## 14. Матрица отличий

| Аспект | Admin (центр) | Coach |
|--------|---------------|-------|
| Спортсмены | Все в центре, CRUD + удаление | Только свои, без удаления |
| Тренеры | CRUD (найм/увольнение) | ❌ |
| Группы | Все в центре, CRUD + удаление | Только свои, без удаления |
| Посещаемость | Просмотр по центру | Отметка на своих занятиях |
| Отчёты | Проверка и утверждение | Только свои (создать → отправить) |
| Мероприятия | Полный CRUD | Просмотр + регистрация |
| Документы | Просмотр, согласование | ❌ |
| Пользователи | CRUD учёток тренеров | ❌ |
| Аудит | Просмотр действий центра | ❌ |
| Аналитика | По центру | ❌ |
| Центр | Редактирование | ❌ |
| Управление ролями | ❌ | ❌ |

---

## 15. Ограничения admin

- Не выходит за пределы своего центра
- Не управляет ролями и правами
- Не создаёт пользователей с ролью `admin` или `superadmin`
- Не видит данные других центров
- Не удаляет центр

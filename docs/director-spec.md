# Спецификация: Интерфейс руководителя всех центров (director)

> Версия 1.0 | Дата: 2026-06-01

---

## 1. Отличия от руководителя центра (admin)

| Аспект | Руководитель центра (admin) | Руководитель всех центров (director) |
|--------|---------------------------|--------------------------------------|
| **Охват** | Только свой центр | Все центры ЦСЕ |
| **Селектор центра** | ❌ | ✅ переключение между центрами / «все центры» |
| **Пользователи** | CRUD в своём центре | Только просмотр всех |
| **Создание учёток** | ✅ тренеров, методистов | ❌ |
| **Роли / Права** | ❌ | ❌ |
| **Спортсмены** | Своего центра | Всех центров |
| **Тренеры** | Своего центра | Всех центров, передача между центрами |
| **Отчёты** | Своего центра | Всех центров, утверждение |
| **Аудит** | Своего центра | Всех центров |
| **Центры** | Редактирование своего | Редактирование своего, просмотр всех |

---

## 3. Селектор центра (Header)

Ключевое отличие — в хедере появляется **`<Select>` с выбором центра**:

- «Все центры» (по умолчанию) — сводка по всей организации
- Конкретный центр — данные только по нему

При выборе «Все центры» — в таблицах колонка «Центр/Филиал», данные отсортированы по центрам.
При выборе конкретного центра — интерфейс идентичен admin, но с сохранением прав director.

---

## 4. Дашборд (`/`)

При «Все центры»:

1. **KPI-карточки:** «Центров: N», «Спортсменов: M всего», «Тренеров: K», «Средняя посещаемость: N%»
2. **Сравнение центров:** таблица/график — филиал → спортсмены → тренеры → посещаемость → отчёты
3. **График посещаемости** по центрам (stacked bar или grouped bars)
4. **Сводка по отчётам:** сколько отправлено/утверждено/просрочено по всем центрам
5. **Последние действия:** аудит всех центров

При выборе конкретного центра — дашборд как у admin, но без кнопок управления.

---

## 5. Спортсмены (`/athletes`)

- Полный CRUD спортсменов **всех центров**
- Доп. колонка: «Центр / Филиал»
- Фильтры: центр, тренер, группа, статус, дисциплина
- Массовые операции: перевод между центрами

---

## 6. Тренеры (`/coaches`)

- Полный CRUD тренеров **всех центров**
- Доп. колонка: «Центр / Филиал»
- **Передача тренера** между центрами
- Фильтры: центр, статус, дисциплина

---

## 7. Группы / Расписание (`/groups`, `/schedule`)

- Полный CRUD групп **всех центров**
- **Передача группы** другому тренеру или в другой центр
- Расписание: просмотр и управление по всем центрам

---

## 8. Посещаемость (`/attendance`)

- Просмотр по всем центрам
- Сравнение центров по посещаемости
- **Не может отмечать** (только тренер)

---

## 9. Отчёты (`/reports`)

- Просмотр **всех отчётов** всех центров
- **Утверждение / отклонение** отчётов
- Фильтры: центр, тренер, статус, период
- Сводка: сколько сдано/утверждено по каждому центру

---

## 10. Документы (`/documents`)

- Просмотр всех документов всех центров
- Согласование

---

## 11. Мероприятия / Соревнования (`/events`, `/competitions`)

- Полный CRUD по всем центрам
- Сводка мероприятий по центрам

---

## 12. Аналитика (`/analytics`)

- Сравнение центров
- Динамика по организации в целом
- KPI тренеров (сводка по всем центрам)

---

## 13. Просмотр (footer) — только чтение

### Пользователи (`/users`)

Список всех пользователей системы.

**Действия:** только просмотр. Создание/редактирование — ❌.

### Центры (`/centers`)

- Список всех центров/филиалов ЦСЕ
- Редактирование **своего** ЦСЕ (название, адрес, телефон)
- Просмотр других центров

### Аудит (`/audit`)

- Логи действий **всех центров**
- Фильтры: центр, пользователь, действие, дата

---

## 14. Профиль (`/profile`)

- Аватар, ФИО, телефон, email
- Должность: «Руководитель всех центров»
- Центр (просмотр)

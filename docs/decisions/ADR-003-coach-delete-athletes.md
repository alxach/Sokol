# ADR-003: Coach может удалять спортсменов

## Status
Superseded by ADR-004

## Date
2025-06-19

## Context
На странице `/athletes` действовало ограничение: кнопка удаления спортсмена была скрыта для роли `coach` (условие `{!isCoach && ...}`). Тренер мог добавлять и редактировать спортсменов, но не мог удалять.

В ходе уточнения ролевой модели выяснилось, что тренеру необходима возможность удалять спортсменов из своей базы (например, при отчислении или переходе в другой клуб). При этом экспорт и импорт Excel должны остаться недоступными для тренера.

## Decision
Убрать условие `{!isCoach && ...}`, оборачивающее кнопку удаления спортсмена в таблице на странице `/athletes`. Кнопка удаления становится доступной всем аутентифицированным пользователям, включая coach.

Ограничения на экспорт (`FileDown`) и импорт (`Upload`) Excel остаются — они по-прежнему скрыты для coach.

## Alternatives Considered
- **Оставить как есть**: coach вынужден обращаться к admin/director для удаления. Создаёт лишний шаг в операционной работе тренера.
- **Вынести удаление в отдельный разрешённый экшн**: избыточно для мок-фазы; усложнение без явной выгоды.

## Consequences
- Тренер может самостоятельно удалять спортсменов.
- Экспорт/импорт остаются закрытыми для coach.
- Изменение затрагивает один файл: `frontend/src/routes/athletes.tsx` (удаление обёртки вокруг кнопки удаления).

# ADR-004: Ролевая модель страницы /athletes для тренера

## Status
Accepted

## Date
2025-06-19

## Context
Страница `/athletes` — реестр спортсменов. Изначально она была одинаковой для всех ролей. Анализ ролевой модели показал, что тренер (coach) работает в иных условиях, чем admin/director:

- Тренер ведёт только своих спортсменов (одна дисциплина, один город)
- Тренер самостоятельно управляет составом групп
- Экспорт/импорт Excel — административная функция
- Фильтр по дисциплинам для тренера избыточен (у него одна дисциплина)

## Decision
Настроить страницу `/athletes` под ролевую модель тренера:

### Изменения

1. **Coach может удалять спортсменов**
   - Убрано условие `{!isCoach && ...}`, оборачивающее кнопку удаления
   - Coach теперь может удалять спортсменов самостоятельно
   - (Экспорт и импорт Excel остались скрыты для coach)

2. **Поиск — только по фамилии**
   - Placeholder изменён с `"Поиск по имени, ID, городу…"` на `"Фамилия"`
   - Поиск по-прежнему ищет по имени, ID и городу, но подсказка ориентирует тренера на основной сценарий

3. **Фильтр дисциплин скрыт для тренера**
   - Чипсы `[Все] [Дзюдо] [Самбо] [Бокс] [ММА] [Борьба]` обёрнуты в `{!isCoach && (...)}`
   - Тренер всегда работает с одной дисциплиной, фильтр не имеет смысла

4. **Инлайн-создание группы в модалке спортсмена**
   - Если у тренера нет групп — показывается кнопка «+ Создать»
   - Если группы есть — кнопка всё равно доступна
   - По клику — поле ввода названия и кнопка «Создать»
   - Группа создаётся с дисциплиной тренера, ID тренера, пустым списком спортсменов
   - После создания группа автоматически выбирается в select
   - Это позволяет тренеру не прерывать поток: добавил спортсмена — создал под него группу

5. **Coach видит только своих спортсменов**
   - Фильтр `accessible` по `a.coach === user.coachName` (было реализовано ранее)

## Files Changed
- `frontend/src/routes/athletes.tsx`:
  - Строки 304–323: убрано `{!isCoach && ...}` вокруг кнопки удаления
  - Строка 222: placeholder `"Фамилия"`
  - Строки 226–240: чипсы дисциплин обёрнуты в `{!isCoach && (...)}`
  - Импорт `Group` из mock-data
  - Состояния `showCreateGroup`, `newGroupName`
  - Функция `handleCreateGroup`
  - Блок «Группа»: условный рендер (select / форма создания) + кнопка «+ Создать» для тренера
- `docs/decisions/ADR-003-coach-delete-athletes.md` — superseded by this ADR

## Consequences
- Тренер получает полноценное управление спортсменами без обращения к admin
- Интерфейс подстраивается под контекст тренера (одна дисциплина, поиск по фамилии)
- Возможность создать группу «на лету» при добавлении спортсмена
- Admin/director видят страницу без изменений

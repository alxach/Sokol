# ADR-005: Разное время занятий для каждого дня недели

## Status
Accepted

## Date
2025-06-19

## Context
В модальном окне «Новое занятие» на странице `/schedules` можно было указать только одно время начала и одно время конца, которое применялось ко всем выбранным дням недели. На практике тренер может проводить одну и ту же группу в разное время в разные дни (например, Пн 09:00–10:30, Ср 15:00–17:00), а также в разных залах.

## Decision
Заменить единые поля `timeStart`/`timeEnd` и `room` на структуру `dayTimes: Record<number, { start: string; end: string; room: string }>`, где ключ — номер дня недели (1–7).

### Детали реализации
- При выборе дня через чипсы — в `dayTimes` добавляется запись с дефолтным временем `09:00–10:30` и залом из общего поля
- При отмене дня — запись удаляется
- Под чипсами дней отображается список выбранных дней, каждый со своими полями `time` (start/end) и залом
- Общее поле «Зал» остаётся на форме — при вводе в него значение копируется в каждый новый выбранный день
- При сохранении `handleAdd` итерируется по `dayTimes` и создаёт `Schedule` для каждого дня с его временем и залом

## Alternatives Considered
- **Оставить как есть**: не решает проблему, тренеру приходится создавать занятие отдельно для каждого дня.
- **Таблица дней со временем в отдельном модальном окне**: избыточно, инлайн-поля под чипсами компактнее и нагляднее.

## Consequences
- Тренер может задать разное время и разный зал для группы в разные дни недели в одном окне
- Обратная совместимость: старые записи не меняются
- Интерфейс остаётся компактным — поля времени и зала появляются только для выбранных дней

## Notes
Все залы имеют типовой проект — помещения во всех центрах идентичны по планировке и оснащению. В текущей реализации зал хранится как произвольная строка (`room: string`). В перспективе, при необходимости строгого учёта загрузки залов или привязки расписания к конкретному филиалу, `room` можно вывести в отдельный справочник с привязкой к центру.

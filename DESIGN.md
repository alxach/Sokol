# Design System: СОКОЛ

## 1. Overview

**Creative North Star: "Штурманская рубка"**

Чистота линий, полный контроль, спокойная уверенность. Как капитанский мостик: каждый прибор на своём месте, данные читаются мгновенно, ничего лишнего.

СОКОЛ — функциональный минимализм с сильной спортивной идентичностью. Интерфейс не привлекает внимания к себе — он направляет внимание тренера или руководителя на данные, сроки, статусы. Прозрачная иерархия, предсказуемые паттерны, никаких декоративных элементов, не несущих информации.

Система явно отвергает эстетику **старых гос. сайтов** — серых, перегруженных таблицами и бюрократических. СОКОЛ не выглядит как система для отчётов перед министерством; он выглядит как рабочий инструмент, которому доверяют.

**Key Characteristics:**
- **Функциональный минимализм.** Каждый пиксель работает на задачу. Никаких украшательств.
- **Спортивная строгость.** Контрастные акценты (сигнальный оранжевый), чёткая типографика, ясная иерархия.
- **Плоские поверхности.** Без лишних теней. Глубина достигается контрастом и цветом.
- **Предсказуемость.** Однотипные действия выглядят одинаково во всех модулях.
- **Мобильная готовность.** Спроектировано для работы в зале, с телефона.

## 2. Colors

Палитра строится вокруг спокойной уверенности спортивного синего, поддержанного глубоким тёмно-синим и сигнальным оранжевым. Цветовые акценты редки и осмысленны (≤10% экрана).

### Primary

- **Sport Blue** (`oklch(0.605 0.128 252)`, hex `#467FC0`): Основной цвет действий. Используется для primary-кнопок, ссылок, активных состояний, акцентных элементов. Спокойный, деловой, техничный оттенок синего.
- **Sport Blue Foreground** (`oklch(0.99 0 0)`, `#FCFCFD`): Текст на primary-фоне.

### Secondary

- **Deep Navy** (`oklch(0.215 0.085 264)`, hex `#09234C`): Фон сайдбара, заголовки хедера, secondary-кнопки. Создаёт ощущение защищённости и серьёзности.
- **Deep Navy Foreground** (`oklch(0.99 0 0)`, `#FCFCFD`): Текст на secondary-фоне.

### Accent

- **Signal Orange** (`oklch(0.78 0.155 70)`, hex `#F4A838`): Акцент для бейджей «скоро», аватара СОКОЛ, статусных индикаторов. Не используется для интерактивных элементов — только для привлечения внимания к особой информации.
- **Signal Orange Foreground** (`oklch(0.215 0.085 264)`)

### Neutral

- **Surface** (`oklch(0.985 0.004 250)`, `#F5F7FA`): Основной фон страниц («Светлый Wash»).
- **Foreground** (`oklch(0.215 0.085 264)`, `#09234C`): Основной цвет текста — Deep Navy (тот же, что secondary).
- **Muted** (`oklch(0.96 0.008 250)`, `#EDF0F5`): Фон неактивных/второстепенных блоков и hover-состояний.
- **Muted Foreground** (`oklch(0.5 0.03 256)`, `#6B7A99`): Вспомогательный текст, подписи, плейсхолдеры.
- **Card** (`oklch(1 0 0)`, `#FFFFFF`): Фон карточек. Чистый белый для контраста с фоном страницы.
- **Border** (`oklch(0.92 0.012 250)`, `#D9DFE8`): Границы элементов, разделители.

### Semantic

- **Destructive** (`oklch(0.6 0.22 25)`, `#D93A3A`): Удаление, ошибки, опасные действия.
- **Success** (`oklch(0.65 0.16 155)`, `#3FAF72`): Подтверждения, успешные операции, статус «активно».

### Named Rules

**The Decisive Accent Rule.** Signal Orange занимает ≤5% любого экрана. Его редкость — в этом его сила. Если оранжевого слишком много, он перестаёт сигнализировать.

**The Sole Authority Rule.** Никаких второстепенных цветов. Sport Blue, Deep Navy и Signal Orange — полная палитра. Каждый цвет выполняет ровно одну роль: первичные действия, структура, акцент.

## 3. Typography

**Display Font:** Manrope (bold, 700)
**Body Font:** Inter (regular, 400)
**Label/Mono Font:** Inter (medium, 500) — same family, different weight

**Character:** Функциональный контраст. Manrope в заголовках даёт спортивную энергию и современный силуэт (благодаря открытым формам и геометрической строгости). Inter в теле — сверхчитаемый нейтральный гротеск с оптимизированными глифами для интерфейсов. В паре они создают ощущение «профессионального спортивного клуба» — достаточно индивидуальности в заголовках, полная нейтральность в данных.

### Hierarchy

- **Display** (700, `clamp(1.5rem, 3vw, 2.25rem)`, 1.2): Крупные заголовки страниц (например, «Дашборд»). Используется исключительно с Manrope.
- **Headline** (600, `clamp(1.25rem, 2vw, 1.75rem)`, 1.3): Заголовки разделов внутри страницы.
- **Title** (600, `1rem`, 1.4): Заголовки карточек, модальных окон.
- **Body** (400, `0.875rem`, 1.5): Основной текст — таблицы, списки, описания. Максимальная длина строки: 75ch.
- **Label** (500, `0.75rem–0.8125rem`, normal): Подписи к полям ввода, бейджи, табы, кнопки. Может быть `uppercase` с `letter-spacing: 0.05em` в sidebar-метках.

**Font feature settings:** `"cv02", "cv03", "cv04", "ss01"` (альтернативные глифы Inter для лучшей читаемости в интерфейсе).

### Named Rules

**The Single Voice Rule.** Для body-текста разрешён только Inter. Manrope запрещён в абзацах, таблицах и интерфейсных элементах. Гармония возникает за счёт того, что каждый шрифт остаётся на своей территории.

## 4. Elevation

Плоская система по умолчанию. Глубина не имитируется тенями — она передаётся через контраст тона: белая карточка на светлом фоне или тёмный сайдбар на navy. Тени используются только как реакция на состояние элемента (hover, focus) и никогда — как структурный элемент.

### Shadow Vocabulary

- **Card Shadow** (`0 1px 2px oklch(0.2 0.05 260 / 0.04), 0 8px 24px -12px oklch(0.2 0.05 260 / 0.08)`): Едва заметная тень под карточками и контейнерами. Достаточная, чтобы отделить поверхность от фона, но недостаточная, чтобы привлечь внимание.
- **Glow Shadow** (`0 10px 40px -10px oklch(0.55 0.13 250 / 0.45)`): Акцентное свечение под элементами в состоянии hover или focus, преимущественно для primary-кнопок.

### Named Rules

**The Flat-By-Default Rule.** Поверхности плоские в покое. Тень — только как реакция на взаимодействие. Если элемент перестал быть интерактивным, тень исчезает.

## 5. Components

Все компоненты следуют философии «чёткие и надёжные»: одинаковый радиус скругления (`0.75rem`, вариации ±4px), единая сетка, предсказуемые состояния.

### Buttons

- **Shape:** Умеренно скруглённые (`rounded-md` = ~10px при базовом радиусе `0.75rem`).
- **Primary (Sport Blue):** Заливка `sport-blue`, текст белый. В hover — затемнение на 10% (`sport-blue` приглушённый). Тень появляется только на hover (glow-shadow).
- **Secondary (Deep Navy):** Заливка `deep-navy`, текст белый. В hover — `opacity 0.8`.
- **Outline:** Прозрачный фон, тонкая рамка `1px solid border`. В hover — заливка `accent` с контрастным текстом.
- **Ghost:** Прозрачный фон, текст нейтральный. В hover — фон `muted`.
- **Link:** Только цвет `sport-blue`, подчёркивание на hover.
- **Size key:** `sm` (h-8, px-3, text-xs), `default` (h-9, px-4, text-sm), `lg` (h-10, px-8), `icon` (h-9 w-9).
- **Icon rule:** Все иконки внутри кнопок — `16px` (`h-4 w-4`), без отступа от текста (`gap-2`).

### Badges / Chips

- **Shape:** Скруглённые (`rounded-md`, примерно `0.5rem`).
- **Default:** `muted` фон, `muted-foreground` текст.
- **Status variants:** `success` (зелёный фон, белый текст), `destructive` (красный), `outline` (тонкая рамка, прозрачный фон).
- **Usage:** Статусы соревнований, фильтры, принадлежность к группе.

### Cards

- **Corner Style:** `rounded-lg` (базовый радиус `0.75rem`).
- **Background:** Чистый белый (`card-bg`).
- **Shadow Strategy:** Используется card-shadow (почти незаметная тень). На hover — без изменения тени (плоское поведение).
- **Border:** Опционально — `1px solid border` для варианта с рамкой (используется в сетках карточек).
- **Internal Padding:** `24px` (`lg`) по вертикали и горизонтали.

### Inputs & Fields

- **Style:** Тонкая рамка (`1px solid border`), светлый фон (`neutral-bg`), скругление `rounded-md`.
- **Focus:** Кольцо `2px` цвета `ring` (sport-blue) с отступом `2px`. Без дополнительной тени.
- **Placeholder:** `muted-foreground` цвет.
- **Error:** Рамка становится `destructive`, поле сопровождается текстом ошибки `text-destructive` размером `label`.
- **Disabled:** `opacity-50`, `cursor-not-allowed`.
- **Search variant:** Иконка лупы слева (16px), внутренний отступ `pl-9`.

### Navigation (Sidebar)

- **Style:** Заливка `deep-navy`, текст `sidebar-fg` (светлый, `oklch(0.92 0.015 250)`). Collapsible (сворачивается до иконок).
- **Default state:** Текст полупрозрачный. **Active state:** Яркий белый текст + `sidebar-accent` фон (`oklch(0.28 0.08 264)`) под активным пунктом.
- **Hover:** Небольшое осветление фона (без отдельной тени).
- **Header:** Логотип в рамке `signal-orange`, инвертированный в белую иконку. Название центра (выпадающий список для директора).
- **Footer:** Иконка «Настройки».
- **Mobile:** Sidebar сворачивается, управляется через `SidebarTrigger` (гамбургер) в хедере.

### Header (App Shell)

- **Style:** `sticky top-0 z-20`, полупрозрачный фон (`bg-card/80`), блюр `backdrop-blur`, нижняя рамка `border`.
- **Content:** Слева — заголовок страницы и подзаголовок. Справа — поиск (на десктопе), иконка уведомлений с оранжевой точкой, блок профиля с инициалами (градиент от primary к secondary) и именем пользователя.

### Table / Data Grid

- **Style:** Чистая таблица без вертикальных линий. Горизонтальные разделители `border` между строками.
- **Header row:** `muted` фон, `muted-foreground` текст, `text-xs uppercase tracking-wider`.
- **Row hover:** `muted` фон строки.
- **Usage:** Спортсмены, расписание, соревнования — везде одинаковая табличная структура.

## 6. Do's and Don'ts

### Do:
- **Do** использовать Sport Blue для всех интерактивных элементов (кнопки, ссылки, переключатели).
- **Do** оставлять достаточно воздуха между карточками и секциями (`gap-6` / `p-6` как минимум).
- **Do** использовать таблицы с горизонтальными линиями и подсветкой строки при hover — это стандартный паттерн для всех списков.
- **Do** давать обратную связь на каждое действие: hover на кликабельных элементах, focus ring на полях, тосты через Sonner.
- **Do** помечать недоступные пункты меню текстом «скоро» (оранжевый бейдж) — это честнее, чем скрывать их.
- **Do** использовать инициалы пользователя (градиент sport-blue → deep-navy) как аватар — это персонально, без лишних затрат на фото.

### Don't:
- **Don't** использовать Signal Orange для интерактивных элементов — он только для статусов и бейджей «скоро».
- **Don't** добавлять декоративные тени к карточкам. Единственная тень — card-shadow, едва заметная.
- **Don't** использовать вертикальные линии в таблицах — только горизонтальные разделители.
- **Don't** использовать яркие фоны, градиенты, glassmorphism или неоновые акценты — это противоречит философии «рабочего инструмента».
- **Don't** смешивать шрифтовые гарнитуры внутри одной секции. Manrope — только заголовки, Inter — всё остальное.
- **Don't** создавать СОКОЛ в тёмной теме с пурпурными градиентами или глянцевыми поверхностями. Если тёмная тема активна — она строгая, матовая, navy-based.
- **Don't** перегружать интерфейс текстом мелкого кегля. Минимальный размер для данных — `0.75rem` (label), для основного текста — `0.875rem`.
- **Don't** проектировать интерфейс только для десктопа. Карточки, таблицы и навигация обязаны работать на экране 360px ширины.
